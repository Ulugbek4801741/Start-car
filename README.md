# START-CAR Racing 3D

Offline Android 3D racing prototype built with Godot 4.

## Current prototype
- Procedural circular race track and scenery
- One placeholder racing car with steering and acceleration
- Touch controls (left, right, gas, brake) and keyboard controls for desktop testing
- Follow camera
- Procedural engine tone generated locally (no downloaded audio)
- No internet, account, or server dependency

## Run
1. Install Godot 4.x.
2. Import this project folder in Godot.
3. Open `Main.tscn` and press Play.

Android export requires Godot's Android export templates and Android SDK/JDK configured in the editor. This repository does not yet contain a built APK.

## Project
`project.godot` is the project configuration and `scenes/Main.tscn` is the startup scene.
